# Figma UI work

- User rule: if Figma MCP Go disconnects or reports `plugin not connected`, stop work immediately and report the connection loss. Resume only after connectivity has been restored and verified.
- Do not invent, approximate, or substitute UI/assets while Figma MCP Go is disconnected, including using cached references as a reason to keep editing.
- For Figma changes, inspect the requested nodes and export their actual artwork. Keep interactive controls native and match the inspected design.
